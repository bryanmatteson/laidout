# Security policy

## Supported versions

Security fixes target the current release series.

| Version | Supported |
| --- | --- |
| 0.3.x | Yes |
| 0.2.x and earlier | No |

## Reporting a vulnerability

Send the report to the contact address published on the
[maintainer's GitHub profile](https://github.com/bryanmatteson). Do not open a
public issue for a suspected vulnerability.

Include the affected version, impact, reproduction steps or a proof of concept,
and known mitigations. The maintainer acknowledges reports within seven days
and coordinates validation, remediation, and disclosure with the reporter.

Never include secrets, access tokens, or private user data in a report.
